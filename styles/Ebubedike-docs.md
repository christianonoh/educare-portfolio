#  Team Gallery Section

This project showcases a **Team Gallery Section** with a clean, responsive, and minimal design.  
It includes a **banner area**, **team member gallery**, and **responsive grid layout** suitable for both desktop and mobile devices.



##  Features

- Responsive grid layout using CSS Grid.  
- Stylish **banner section**.  
- Clean and modern UI using soft colors (`rgb(225, 248, 248)` and `rgb(28, 107, 28)`).  
- Interactive **"Join" button** with hover effects.  
- Fully responsive across mobile, tablet, and desktop screens.



1. Team Gallery Section (.team-gallery-section)

Sets a centered container with soft background color.

Uses padding and limited width for a neat layout.

Titles (h5) styled with green text.


2. Gallery Layout (.team-gallery)

Uses CSS Grid with three columns by default.

Even spacing (gap: 10px) for consistent alignment.

Automatically adjusts to smaller screens.

3. Gallery Cards (.gallery-card)


Each card includes:

Background color matching the section.

Image and text elements stacked vertically.

Responsive image sizing with object-fit: cover.


4. Gallery Banner (.gallery-banner)

Displays a banner with a background image and overlay color.

Uses Flexbox for left-right alignment.

Includes:

Left side: Logo, title, and short description.

Right side: “Join” button with hover effect.


5. Responsive Design

Adjusts layout for different screen sizes:

≤768px: Gallery switches to 2 columns.

≤480px: Gallery becomes a single column.

≤600px: Banner stacks vertically with centered text.
