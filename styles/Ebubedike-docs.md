#  Team Gallery Section

This project showcases a **Team Gallery Section** with a clean, responsive, and minimal design.  
It includes a **banner area**, **team member gallery**, and **responsive grid layout** suitable for both desktop and mobile devices.



##  Features

- Responsive grid layout using CSS Grid.  
- Stylish **banner section**.  
- Clean and modern UI using soft colors (`rgb(225, 248, 248)` and `rgb(28, 107, 28)`).  
- Interactive **"Join" button** with hover effects.  
- Fully responsive across mobile, tablet, and desktop screens.
