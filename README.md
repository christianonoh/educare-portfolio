# 🎓 Educare Portfolio Bootcamp Project

Welcome to the **Educare Portfolio Project**
This is a collaborative exercise where we’ll rebuild a simple one-page portfolio inspired by the design on [winexviv.com](https://winexviv.com/).  

The project is divided into **three main groups**, each with a specific focus:

---

## 🏗️ Group 1 — Structure (HTML)
**Goal:** Build the page layout using clean, semantic HTML.

**Tasks:**
- Create a folder named `structure/`
- Inside it, add your files (`index.html`, assets, etc.)
- Write a **`docs.md`** file explaining:
  - What sections you created
  - How your HTML is organized
  - Any dependencies or linked files

---

## 🎨 Group 2 — Styles (CSS)
**Goal:** Style the project to match the **Winexviv** look and feel (colors, spacing, typography).

**Tasks:**
- Create a folder named `styles/`
- Add your CSS files inside it (e.g., `main.css`, `theme.css`)
- Write a **`docs.md`** file explaining:
  - How to apply your styles to the structure group’s layout
  - Color and font choices
  - Responsive design decisions

---

## ⚡ Group 3 — Events (JavaScript)
**Goal:** Add interactivity and animations (e.g., menu toggle, scroll effects, form validation).

**Tasks:**
- Create a folder named `events/`
- Add your JavaScript files (`main.js`, etc.)
- Write a **`docs.md`** file explaining:
  - What each script does
  - How to attach your scripts to the HTML
  - Any external libraries or dependencies

---

## 💡 General Guidelines
- Follow good naming conventions and folder structure.  
- Commit regularly with meaningful messages.  
- Review other groups’ code before merging.  
- Make sure everything works together when combined.

---

## 🚀 Final Goal
Recreate a clean, elegant **one-page portfolio** inspired by [winexviv.com](https://winexviv.com/) — simple, modern, and professional.
