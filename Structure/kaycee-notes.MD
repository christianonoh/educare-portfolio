# Educare Portfolio — HTML Structure

## Overview
This project contains the basic structure for a simple website built using plain HTML. It includes two main pages — **Home** and **About** — each serving a specific purpose within the site.

---

## Files

###  index.html
The **Home Page** of the website.
- Contains a navigation bar with links to:
  - Home
  - About
  - Contact
  - Services
- Includes a hero section introducing the company with the heading contents

###  about.html
The **About Page** of the website.
- Displays an “About Us” section with a headline and contents
- Includes an image (`educare-1.jpg`) to represent the company.
- Contains descriptive text about the company’s mission.
- Shows basic company stats like:
  - **60+** total team members  
  - **4y+** years of operation

---

## Features
- Semantic HTML structure.
- Simple navigation between pages.
- Responsive meta tags for mobile compatibility.
